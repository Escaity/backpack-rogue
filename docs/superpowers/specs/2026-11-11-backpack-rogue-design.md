# Backpack Rogue（仮称）ゲームデザイン

- 作成日：2026-11-11
- 状態：設計合意済み（保留事項あり）
- プラットフォーム：ブラウザ（HTML / TypeScript）、グラフィックは簡略表現（図形・絵文字・テキスト）

## 1. コンセプト

エクストラクション型のダンジョン探索と、装備配置型のオートバトルを組み合わせたシングルプレイヤーゲーム。

- 拠点から潜入し、戦利品を持って脱出口から生還する。死ねば持ち込んだ物も拾った物もすべて失う。
- 最初は何も持っていない。潜入に成功するたびに倉庫の装備が整っていく。
- アイテムは増え続けるので、全ロスト・強化・合成・修理・倉庫容量などで消費させる。
- 戦利品はバッグのマスを使う。欲張るほど予備装備を持てなくなり、持ち帰りのリスクが上がる。

## 2. ゲームループ

```
拠点 ──準備──▶ 潜入 ──探索・戦闘・略奪──▶ 脱出成功 ──▶ 拠点（戦利品を倉庫へ）
                  │
                  └─▶ 死亡 ──▶ 装備とバッグの中身をすべて失う
```

1. **準備**：倉庫から装備を選んで装着し、バッグに予備品を詰める。持ち込んだ物はすべて失うリスクを負う。
2. **潜入**：部屋マップを探索し、モンスターやライバルと戦い、宝箱を開けて脱出口を目指す。
3. **脱出**：装備とバッグの中身がそのまま倉庫に入る。
4. **拠点**：売却、購入、強化、修理、合成を行い、次の潜入に備える。

### 手持ちゼロの救済
- 潜入のたびに**無料のボロ装備一式**（錆びた短剣、布の服、黒パンなど）を受け取れる。
- 全ロストしても必ず再挑戦でき、進めなくなる状況を防ぐ。

## 3. 装備（人型インベントリ）

### 装備枠（12枠＋消費アイテム枠1〜3）

| 区分 | 枠 |
|---|---|
| 武器 | 右手、左手 |
| 防具 | 頭部、胴体、ベルト、脚部、靴、手袋、腕 |
| 装飾品 | 指輪×2、ネックレス×1 |
| 消費アイテム枠 | 1〜3枠（ベルトによって変わる） |

### 人型レイアウト

```
                ┌──────┐
                │ 頭部 │
        ┌──────┼──────┼──────┐
        │指輪R │ネック│指輪L │
┌──────┼──────┼──────┼──────┼──────┐
│ 右手 │  腕  │ 胴体 │ 手袋 │ 左手 │
└──────┴──────┼──────┼──────┴──────┘
                │ベルト│
                ├──────┤
                │ 脚部 │
                ├──────┤
                │  靴  │
                └──────┘
      消費アイテム枠：[  ][  ][  ]
```

- レイアウトは、将来の隣接シナジー（保留中）に備えて人型のまま固定する。
- 現時点では、枠の位置は戦闘に影響しない。

### ベルトと消費アイテム枠

| ベルト | 消費アイテム枠 |
|---|---|
| なし | 1 |
| 布の帯 | 2 |
| 革のベルト | 3（最大） |

ベルトを外したり付け替えたりして枠が減った場合、はみ出した消費アイテムはバッグに戻す。バッグに入らなければ、その場に捨てる。

## 4. バッグ

- 持ち運び専用のグリッド。**戦闘には参加しない**。
- アイテムには形（1×1、1×2、2×2、L字など）があり、回転して配置できる。
- 戦利品、金貨、予備装備、予備の消費アイテムを入れる。
- 金貨もマスを使う（1マスに最大50枚）。
- **バッグ自体が装備品**で、種類によって広さが変わる（例：布袋 4×3、革の背嚢 5×4、冒険者の大鞄 6×5）。死亡時はバッグも失う。
- ダンジョン内では、装備枠とバッグの間でいつでも入れ替えられる（戦闘中を除く）。

## 5. 戦闘（クールタイム制オートバトル）

- 1対1のオートバトル。プレイヤーは介入しない。目安の長さは10〜20秒。
- ステータス：**HP / スタミナ / 防御値**（回避、攻撃速度などは装備で補正する）。

| 区分 | 動き |
|---|---|
| 武器（右手・左手） | クールタイムごとに攻撃する。スタミナを消費し、足りなければ回復を待つ |
| 防具・装飾品 | 基本は常時効果（HP、防御、回避、攻撃速度など）。一部はクールタイム付きの効果を持つ（例：指輪「5秒ごとにHPを2回復」） |
| 消費アイテム | 条件を満たすと発動する（例：HP50%以下でポーション）。使うと消える |

- 一定時間を過ぎると、両者が疲労ダメージを受け続ける（長期戦の防止）。
- 戦闘ごとに装備の耐久度が減る。0になると壊れて消える。
- 戦闘中は人型レイアウト上で、発動した装備の枠を光らせて表示する。

### 戦闘後
- モンスターに勝つと、ドロップ品の中から**バッグに収まる分だけ**持ち帰れる。
- ライバルに勝つと、相手の装備とバッグの中身がすべて表示され、好きな物を奪える。バッグそのものを奪って乗り換えることもできる。

## 6. ダンジョン

- **部屋マップ**：5×5程度の部屋がつながったマップ。クリックで隣の部屋に移動する。
- **部屋の種類**：空き部屋、モンスター、宝箱、罠、回復の泉、下り階段、脱出口。
- **見通し**：隣の部屋の中身は「気配」程度しかわからない（例：物音、金属の匂い）。
- **階層**：浅層から始まり、下り階段で深層へ進める。深いほど敵も戦利品も強くなる。

### 時間圧
- 移動、戦闘、宝箱の開錠など、行動のたびに時間（ターン）が進む。
- 一定ターンごとに、外周の部屋から順に**瘴気で閉鎖**される。閉鎖された部屋にいると毎ターンダメージを受ける。
- **脱出口**は途中から2〜3か所にランダムで現れる。脱出には数ターンの詠唱が必要。

## 7. AIライバル冒険者

- 1つの階層に3〜5人。プレイヤーと**同じルール**（装備、バッグ、戦闘、略奪、脱出）で動く。
- 性格ごとの行動：
  - **漁り屋**：戦闘を避けて宝箱を開けて回る。先を越されると部屋が空になる。
  - **狩人**：プレイヤーを追跡する。
  - **臆病者**：弱ると逃げ、脱出口を目指す。
- ライバル同士やモンスターとも戦って消耗する。弱ったライバルや死体を漁れる。
- 隣の部屋にいると足音などの気配がわかる。
- 同じ部屋に入ると戦闘になる。靴の性能によっては、戦闘前に逃走を試みられる。

## 8. 拠点と経済

### 施設

| 施設 | できること |
|---|---|
| 倉庫 | 持ち帰った物を保管する。グリッド制（初期 8×6）。金貨を払って拡張する |
| 商人 | アイテムの売却。基本的な装備や消耗品の購入（品揃えは潜入ごとに入れ替わる） |
| 鍛冶屋 | 強化、修理、合成 |

### 鍛冶屋
- **強化**：金貨を払って＋1〜＋5まで強化する。段階が上がるほど費用が増える。必ず成功する。
- **修理**：減った耐久度を金貨で回復する。
- **合成**：決まったレシピのアイテムを消費して、上位アイテムを作る（例：鉄の兜＋獣の毛皮 → 毛皮張りの兜）。

### レアリティ
- ボロ／普通／上質／希少／伝説の5段階。
- レアリティが高いほど、ランダムな追加効果（例：攻撃速度+5%、最大HP+10）が多く付く（0〜3個）。

### アイテムの消費先

| 消費先 | 仕組み |
|---|---|
| 死亡ロスト | 装備とバッグの中身をすべて失う |
| 強化・修理 | 金貨を消費する（売却で得た金貨の主な使い道） |
| 合成 | 素材アイテムを消費する |
| 耐久度 | 0になると壊れて消える |
| 倉庫容量 | 溢れたら売るか捨てる。拡張に金貨を消費する |
| 消費アイテム | 使うと消える |
| 深層の入場料 | 金貨または鍵を消費する |

### 深層への入場
- 浅層は無料で入れる。
- 深層には、入場料（金貨）か、ダンジョンで拾った鍵が必要。

### 保存
- ブラウザのローカルストレージに保存する（サーバーは使わない）。

## 9. 実装方針（概要）

ゲームのルールは、表示から切り離した純粋なTypeScriptのモジュールにし、単体テストできるようにする。乱数はシード付きにして、戦闘やマップ生成を再現できるようにする。

| モジュール | 役割 |
|---|---|
| `items` | アイテム定義、レアリティ、追加効果、形状 |
| `equipment` | 装備枠、ベルトによる消費アイテム枠、ステータス計算 |
| `grid` | バッグと倉庫のグリッド配置（形状、回転、衝突判定） |
| `combat` | クールタイム制のオートバトル（固定時間ステップで進め、ログを出力する） |
| `dungeon` | 部屋マップの生成、時間経過、瘴気、脱出口 |
| `rivals` | ライバルの行動AI（性格ごとの方針） |
| `town` | 倉庫、商人、鍛冶屋（強化、修理、合成） |
| `save` | ローカルストレージへの保存と読み込み |
| `ui` | 画面表示と操作（ゲームのルールを持たない） |

### 最初に作る範囲（MVP）
1. 装備枠とバッグのグリッド、ステータス計算
2. オートバトル（モンスター戦のみ）
3. 浅層1階分の部屋マップ、時間経過、瘴気、脱出口
4. 拠点の倉庫と商人（売却、購入）、ボロ装備の配布、保存

その後、ライバル → 鍛冶屋（強化、修理、合成）→ 深層とレアリティ、の順に追加する。

## 10. 保留事項

- **人型レイアウトの隣接シナジー**（紋章による接続案など）：保留。レイアウトは維持し、後から追加できるようにしておく。
- **冒険者ランク**（死んでも失わない進行）：保留。
- **両手武器と盾の扱い**：両手武器が右手と左手の2枠を使うかどうか、盾を左手専用にするかどうかは、実装時に決める。
- **数値バランス**（ダメージ、クールタイム、価格、瘴気の速度など）：試作しながら調整する。
- **合成レシピの一覧**：アイテムの定義と合わせて作る。
