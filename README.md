# Backpack Rogue

ブラウザで遊ぶ、持ち物管理型のローグライクです。地下に潜り、アイテムを集めて、脱出口から生きて帰ります。失敗すると持ち物をすべて失います。

- **潜入 → 脱出の繰り返し**：潜るたびに装備が揃っていく。死ぬと持ち込んだ装備は全ロスト。
- **バッグの配置が戦闘になる**：バッグの列がそのまま戦闘のタイムラインになる（シーケンサー戦闘）。武器は主力、バッグの道具は補助。
- **地下 3 階まで**：階段で降りるほど危険で実入りが良い。脱出口は隠れていて、開閉しながら場所を変える。
- 絵は簡略化した絵文字表示。保存はブラウザの localStorage。

## 遊び方

```bash
npm install
npm run dev
```

表示された URL（通常 http://localhost:5173）をブラウザで開きます。

## 開発

```bash
npm test          # テスト（クリア率の回帰テストを含む。少し時間がかかります）
npm run typecheck # 型チェック
npm run build     # 型チェック + 本番ビルド
```

- TypeScript / Vite / Vitest、依存はそれだけ。描画は素の DOM。
- `src/core`：ルールのすべて。副作用なし、シード付き乱数。`src/ui`：描画と入力のみ。
- `tests/sim`：基準プレイのボット。階ごとのクリア率（地下 1 階 約 50%、2 階 約 40%、3 階 約 30%）を測る。
- 設計書と実装計画は `docs/superpowers/` にあります。
